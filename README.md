# Tic Tac Toe – Q-Learning AI

An interactive Tic Tac Toe game featuring an AI opponent trained using Q-learning.

## Features
- Interactive web-based gameplay
- AI opponent using Q-learning
- Multiple difficulty levels
- AI training using Python
- Q-table-based decision making

## Tech Stack
- HTML
- CSS
- JavaScript
- Python
- Q-Learning
